# S2x-upstream

This is a staging fork of [Brentdevent/S2x](https://github.com/Brentdevent/S2x) for pull requests from ChronoRixun. Nothing else lives here.

- `master` is Brent's master, unchanged.
- Every other branch is one change, cut from his master, offered (or waiting to be offered) as its own pull request. Each holds a single commit whose message gives the cause first.
- The fork with the features, and the list of what has been offered upstream, is [ChronoRixun/S2x-CR](https://github.com/ChronoRixun/S2x-CR).

Bugs and ideas go to S2x-CR's issues, or to Brent's repo if they are about upstream.
